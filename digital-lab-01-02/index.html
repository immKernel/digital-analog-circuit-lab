01｜集成逻辑门电路及其应用

PDF 2–5 页

实验一的三个目标：熟悉实验箱的开关、LED、脉冲源等器件；测试与非门、反相器、三态门的功能；学习利用这些器件构成应用电路。

逻辑 0、逻辑 1 是什么

数字电路不是把“1”看成某个固定电压，而是按器件规定的阈值，把输入电压判定为逻辑低或逻辑高。

EXPERIMENT 01 · 74LS125

04｜三态门：输出不仅有 0 和 1

第三种状态叫高阻态 Z

普通逻辑门的输出为 0 或 1。三态缓冲器 74LS125 还可以让输出端暂时不主动驱动外部线路，称为高阻态（Z）。它不是 0，也不是 1。

EN̅ = 0 ⇒ Q = A
EN̅ = 1 ⇒ Q = Z

原书图 1-7 包含三种应用：多路开关、双向传输、单向数据传输。本质都是“多个驱动源分享一根总线，但同一时刻应只允许合适的一方驱动”。

反相器为什么能产生方波？

反相器输出接到由电阻、电容组成的反馈路径中，电容不断充电、放电，使输入跨过逻辑阈值，输出翻转，从而形成周期振荡。原书给出近似关系：

实验一 ⑥ / ⑦

抢答器与 RS 消抖

四路抢答器：原书要求使用四输入与非门和反相器组成四人抢答器。初始全部未抢答；某人先按下对应开关，锁存该通道，使对应 LED 点亮，并阻止其他通道改变结果。

基本 RS 触发器：用两个交叉耦合的与非门保存一个状态。机械开关在切换时会发生抖动，RS 锁存使输出保持稳定。

抓住“记忆”的区别：组合逻辑的输出只看当前输入；RS 触发器还与过去状态有关，因此属于具有状态的电路。

原书还涉及一阶 RC 单稳态脉冲形成过程，给出恢复时间近似 T ≈ 0.7RC，具体波形要以实验箱测量结果为准。

EXPERIMENT 02 · FOUR BIT ADDER

07｜74LS83 / 74LS283：四位全加器

指导书图 2-4 给出两种四位全加器的不同管脚位置；图 2-5 展示了由四个一位全加器级联的逻辑结构。切勿以为 74LS83 与 74LS283 引脚完全兼容。

一位全加器怎么产生进位？

本位输入 A、B，加上从低位来的进位 Cin，得到本位和 S 与送向高位的进位 Cout：

S = A ⊕ B ⊕ Cin
Cout = A·B + Cin·(A ⊕ B)

四个一位全加器首尾相接，让每级进位流入更高一位：

FA1 ➜ FA2 ➜ FA3 ➜ FA4
C0 是低位输入进位，C4 是最终向高位的输出进位。实验书用 F4 F3 F2 F1 表示四位和。

EXPERIMENT 02 · ADD / SUBTRACT

09｜四位加减法器：为什么减法要加 1？

核心：二进制减法可以变成加法

原书图 2-8 在被减数 A 的每一位之外，将另一组输入 D 与控制信号 M 做异或，然后把结果接入全加器的 B 端。

当 M=0：不反相，并使 C0=0，得到 A+D。

当 M=1：逐位取反，并使 C0=1，得到 A+¬D+1，这就是四位补码减法。

这里的 C0 必须跟随模式 M：M=0 → C0=0；M=1 → C0=1。这就是原书思考题“减法为什么 C0 接 +VCC”的关键。

一眼看清“溢出/借位”

加法

四位输出超过 15 时，C4=1。比如 15+1，低四位变成 0000，但 C4=1，五位结果为 10000。

减法

对无符号四位数，采用 A+¬D+1 时，C4=1 通常表示没有借位，C4=0 表示发生借位。低四位结果按模 16 表示。

例如 3−5：4 位计算会得到 1110（无符号是 14，按四位补码解释为 −2），且 C4=0。单看 F4…F1 不足以判断想要的数值解释。
EXPERIMENT 02 · CODE CONVERSION

10｜用全加器把 8421 码变成余 3 码

余 3 码到底是什么？

8421 码（BCD）把十进制 0–9 分别表示为四位二进制。余 3 码就是在每个合法的 8421 编码上加二进制 0011（也就是十进制 3）。

余 3 码 = 8421 BCD + 0011

原书要求：使用 74LS83，不增加其他器件，参考图 2-9。做法是将一个四位输入端固定成 0011，另一端连接 BCD，C0 设为 0，读取输出 F4…F1。

BCD 1010–1111 并不是合法的单个十进制数字编码；原书要求主要是合法 0–9 的转换。
