## 二、实验内容（原理分析、电路图）

### 2.1 异或门（74LS86）及其运算特性
异或逻辑表达式：$Y = A \oplus B = \bar{A}B + A\bar{B}$。
- **可控反相特性**：
  - 当 $B = 0$ 时：$Y = A \oplus 0 = A$（原码传输）；
  - 当 $B = 1$ 时：$Y = A \oplus 1 = \bar{A}$（反相输出）。
- **半减器原理（图 2-3）**：差数 $D = A \oplus B$，借位数 $C_i = \bar{A} \cdot B$。
- **奇偶校验原理（图 2-7）**：多位异或 $Y = A \oplus B \oplus C \oplus D$。输入中“1”的个数为奇数时输出 1，为偶数时输出 0。

### 2.2 四位二进制全加器（74LS83）
74LS83 具有两组 4 位输入 $A_4..A_1$ 和 $B_4..B_1$，一位低位进位输入 $C_0$，输出 4 位和 $S_4..S_1$（或 $F_4..F_1$）及高位进位 $C_4$。满足算术全加公式：
$$\sum = A + B + C_0$$

### 2.3 四位加法/减法器原理（图 2-8）
在微机运算器中，减法通过**加补码**实现：$[A - B]_补 = [A]_补 + [-B]_补 = A + \bar{B} + 1$。
- **控制端 $M = 0$ 时（加法模式）**：
  加数经异或门 $B_i \oplus 0 = B_i$ 输出原码；同时低位进位输入 $C_0 = M = 0$。全加器执行：$F = A + B + 0 = A + B$。
- **控制端 $M = 1$ 时（减法模式）**：
  加数经异或门 $B_i \oplus 1 = \overline{B_i}$ 逐位取反；同时低位进位输入 $C_0 = M = 1$。全加器执行：$F = A + \bar{B} + 1 = A - B$。

### 2.4 8421 BCD 码转余 3 码电路（图 2-9）
余 3 码是在 8421 码的基础上加上十进制数 3 形成的无权码。利用 74LS83，将输入 8421 码接 $A$ 端，将固定二进制常数 $0011$（即十进制 3）接 $B$ 端（$B_4=0, B_3=0, B_2=1, B_1=1$），$C_0$ 接地（0），输出端直接输出对应的余 3 码，无需额外器件。

## 六、思考问答题

### 思考题 1：本实验中，为什么做加法运算时全加器的 $C_0$ 接地（0），做减法运算时 $C_0$ 接 $+V_{cc}$（1）？
**答：** 
计算机二进制减法运算采用补码原理实现：
$$A - B = A + [-B]_补 = A + (\bar{B} + 1)$$
1. **做加法时（$M=0$）**：异或门输出 $B_i \oplus 0 = B_i$（原码），且不应有额外的初始进位，因此低位进位输入端 $C_0$ 必须接地（0），全加器执行：
   $$F = A + B + 0 = A + B$$
2. **做减法时（$M=1$）**：异或门输出 $B_i \oplus 1 = \overline{B_i}$（求反码）。为了获得加数的真补码，必须在反码的最低位**“加 1”**。将 $C_0$ 接高电平（1）正好提供了补码运算所需的这个最低位“+1”，全加器执行：
   $$F = A + \bar{B} + 1 = A - B$$
因此，$C_0$ 接高电平是补码减法运算不可或缺的组成部分！

### 思考题 2：用异或门和与非门组成一个逻辑电路，使四位二进制数相等时（即四个变量相同），输出为 1，否则为 0。试画出逻辑电路图。
**答：**
1. **逻辑表达式推导**：
   判断两个 4 位二进制数 $A(A_4A_3A_2A_1)$ 和 $B(B_4B_3B_2B_1)$ 是否相等（或 4 个输入变量 $A, B, C, D$ 是否全为 1 或全为 0）：
   题目要求四个变量相同，即全部为 0 或全部为 1：
   $$L = \overline{A} \cdot \overline{B} \cdot \overline{C} \cdot \overline{D} + A \cdot B \cdot C \cdot D$$
   或者若题意为“比较两个两位数 $A_1A_0$ 与 $B_1B_0$”或“比较四位对应相等”：
   - 当比较四位一一相等时，每位相等即同或逻辑：$X_i = \overline{A_i \oplus B_i}$；
   - 整体相等要求各位同时相等：$L = X_4 \cdot X_3 \cdot X_2 \cdot X_1 = \overline{\overline{X_4 \cdot X_3 \cdot X_2 \cdot X_1}}$；
2. **电路结构组成**：
   - 第 1 级：用 4 个异或门分别接入两组数的对应位 $(A_1, B_1) \dots (A_4, B_4)$，输出异或结果；
   - 第 2 级：用 4 个反相器将异或结果变为同或（或者直接接入与非门）；
   - 第 3 级：利用一片 4 输入与非门（74LS20）将 4 位比较结果汇集，后端接 1 个反相器输出，当且仅当每一位均相同时输出高电平 1！
