### 1.2 双踪示波器荧光屏坐标测量原理与旋钮分区

示波器屏幕为标准的 $8 \times 10$ 格（厘米）坐标网格：
- **垂直偏转因数（Volts/div）**：控制波形幅度。实测峰-峰值：
  $$U_{p-p} = \Delta Y \, (\text{格数}) \times (\text{Volts/div})$$
- **水平时基因数（Time/div）**：控制扫描速度。实测信号周期：
  $$T = \Delta X \, (\text{格数}) \times (\text{Time/div}) \implies f = \frac{1}{T}$$
- **毫伏表与示波器换算关系（仅限正弦波）**：
  $$U_{rms} = \frac{U_p}{\sqrt{2}} = \frac{U_{p-p}}{2\sqrt{2}} \approx \frac{U_{p-p}}{2.828}$$

![示波器荧光屏坐标测量原理与核心控制旋钮分区](./images/fig2_oscilloscope_panel.svg)

### 1.3 示波器 8 种异常波形诊断与排除秘籍（教材思考题重点）

在实际调试中，荧光屏常因旋钮设置不当出现异常情况（对应指导书图 1-3），诊断及排除策略如下：

![8种异常波形诊断与排除图解](./images/fig3_waveform_troubleshooting.svg)

| 异常情景（图 1-3） | 典型现象 | 根源诊断 | 旋钮排除方法 |
| :---: | :--- | :--- | :--- |
| **(a)** | 仅有一光斑或垂直竖线 | 扫描关闭或误置于 **X-Y 模式** | 调节扫描时基 `Time/div` 切出 X-Y 档；触发模式置于 `AUTO` |
| **(b)** | 波形严重偏上/偏下出界 | 垂直位移偏置过大或含有较大直流偏置 | 调节 `Y-POS` / `X-POS`；输入耦合开关切至 **AC 档**（隔直） |
| **(c)** | 垂直幅度极小一条窄带 | `Volts/div` 衰减档位过大，或探头在 10X 档 | 逆时针调小 `Volts/div`（如由 5V/div 调至 0.5V/div） |
| **(d)** | 波形密集如一条光带 | 扫描时基 `Time/div` 档位过大（扫描过慢） | 顺时针调小 `Time/div`（如由 10ms/div 调至 0.25ms/div） |
| **(e)** | 水平方向仅有半个波形被拉伸 | 扫描时基 `Time/div` 档位过小（扫描过快） | 逆时针增大 `Time/div`，使屏幕完整呈现 **2~3 个周期** |
| **(f)** | 左右晃动、双影重叠跑动 | 触发同步失锁，触发电平（Level）不在信号范围内 | 确认触发源选择输入通道（CH1/CH2）；轻旋 `Trigger Level` 旋钮锁定 |
| **(g)** | 顶部或底部平头削顶 | 信号源幅度过大，超出线性范围失真 | 调小信号源输出细调，或按下信号源 **20dB / 40dB 衰减键** |
| **(h)** | **标准规范波形** | 居中、2~3个周期、垂直占屏 1/2~2/3、线条最细清晰 | **微调旋钮 CAL 必须顺时针旋死在校准位**，确保读数真实可靠 |

### 1.4 稳压二极管（2CW53）测试原理与伏安特性

稳压二极管工作于**反向击穿状态**。在反向击穿区，电流急剧变化，但端电压几乎恒定在稳压值 $U_Z$：

![稳压二极管测试原理与伏安特性](./images/fig4_zener_diode_test.svg)

- **实测回路电流公式**：
  $$I = \frac{U_{cc} - U_o}{R} \quad (R = 1\text{k}\Omega)$$
- **实测数据规律（表 1-1）**：
  当直流电源 $U_{cc}$ 分别调整为 $9\text{V}, 12\text{V}, 14\text{V}, 15\text{V}$ 时，实测端电压 $U_o$ 基本稳定在标称击穿电压（约 $6.5\text{V}\sim 7.5\text{V}$），增加的电压完全被限流电阻 $R$ 分担承受。

### 1.5 发光二极管（LED）测试与电流-亮度响应

发光二极管工作在**正向导通状态**，具备单向导电性，正常工作电流约数毫安至十几毫安：

![发光二极管测试原理电路与亮度-电流响应关系](./images/fig5_led_test.svg)

- **工作电流公式**：
  $$I = \frac{U_{cc} - U_o}{R} \quad (R = 300\Omega)$$
- **实测响应（表 1-2）**：
  - $U_{cc} = 3\text{V} \implies U_o \approx 1.85\text{V}, I \approx 3.8\text{mA}$（微亮）
  - $U_{cc} = 4\text{V} \implies U_o \approx 1.95\text{V}, I \approx 6.8\text{mA}$（明亮）
  - $U_{cc} = 5\text{V} \implies U_o \approx 2.05\text{V}, I \approx 9.8\text{mA}$（很亮）

### 1.6 万用表判别二极管与三极管（3DG/3CG）引脚图解

![万用表判别半导体器件极性图解](./images/fig6_multimeter_pinout_check.svg)

#### 关键防坑提示：机械指针表 vs 数字表极性差异
- **机械指针式万用表（$R \times 1\text{k}\Omega$ 挡）**：内部**黑表笔接电池正极 (+)**，**红表笔接电池负极 (-)**。当指针大偏转（低阻）时，黑表笔接触的是二极管阳极（正极）。
- **数字式万用表（二极管挡）**：面板**红表笔为正 (+)**，**黑表笔为负 (-)**。显示值为管压降（硅管 $0.5\sim0.7\text{V}$，反向显示溢出 `OL`）。

#### 晶体三极管（3DG 型 NPN / 3CG 型 PNP）判别技巧
1. **基极 b 与管型判定**：固定一个引脚，用另一表笔测量与其余两脚的导通阻值。若两次均导通（低阻），则该脚为基极 $b$。数字表红笔为固定脚为 **NPN**（如 3DG6），黑笔为固定脚为 **PNP**（如 3CG12）。
2. **集电极 c 与发射极 e 判定**：TO-18 金属圆帽封装中，**紧靠金属凸起定位点的是发射极 $e$**，隔着基极对称的一侧为集电极 $c$。亦可使用数字表面板的 $h_{FE}$ 插槽直接验证。

## 二、课后思考题标准答案与原理解析

### 思考题 1：说明使用示波器观察波形时，为达到下列要求，调节哪些旋钮？
1. **波形清晰且亮度适当**：
   - 调节“辉度（Intensity）”控制电子束密度；
   - 调节“聚焦（Focus）”和“辅助聚焦”使扫描线收缩至最细最清晰。
2. **波形在荧光屏中央且大小适中**：
   - 调节“Y轴位移（Y-POS）”和“X轴位移（X-POS）”控制中心；
   - 调节垂直衰减“Volts/div”使波形上下占屏 1/2~2/3；
   - 调节水平时基“Time/div”使波形水平展开适度。
3. **波形完整**：
   - 调节水平扫描时间“Time/div”，选取合适扫描速率，使屏幕显示 2~3 个完整的正弦波。
4. **波形稳定**：
   - 调节“触发电平（Trigger Level）”旋钮，使触发点落在信号峰峰值范围内；
   - 检查“触发源（SOURCE）”是否设定在被测通道（CH1 或 CH2）；
   - 设置触发方式为“AUTO”或“NORM”。

---

### 思考题 2：荧光屏出现图 1-3 所示情形是哪些旋钮不对？
- **情景 (a)**：未启动水平锯齿波扫描或误置于 X-Y 模式。将模式切出 X-Y，顺时针选定 Time/div。
- **情景 (b)**：位移旋钮（Y-POS / X-POS）调偏，或含有较大直流偏置。调平位移旋钮并切换为 AC 耦合。
- **情景 (c)**：垂直衰减因数 Volts/div 档位太大。逆时针调小 Volts/div。
- **情景 (d)**：水平扫描速度太慢（Time/div 太大）。顺时针减小 Time/div 档位。
- **情景 (e)**：水平扫描速度太快（Time/div 太小）。逆时针增大 Time/div 档位。
- **情景 (f)**：触发未同步，电平旋钮偏离。微调 Trigger Level，确认触发源对应正确通道。
- **情景 (g)**：输入信号幅度过大失真削顶。调小信号源输出电压或启用衰减档。

---

### 思考题 3：稳压二极管在正常工作条件下，限流电阻 $R$ 的取值应满足什么条件？
稳压二极管要稳定工作，必须满足两个边界条件：
1. **防止稳压失效（不脱离反向击穿区）**：在输入直流电压最小（$U_{I\min}$）且负载取最大电流（$I_{L\max}$）时，流经稳压管的电流仍必须大于最小稳定电流 $I_{Z\min}$；
2. **防止器件过载烧毁（不超过最大允许功耗）**：在输入直流电压最大（$U_{I\max}$）且负载开路断开（$I_{L} = 0$ 或 $I_{L\min}$）时，全部电流注入稳压管，仍不得超过最大允许稳定电流 $I_{Z\max}$。

综合列出不等式组推导，限流电阻 $R$ 必须满足：
$$\frac{U_{I\max} - U_Z}{I_{Z\max} + I_{L\min}} \le R \le \frac{U_{I\min} - U_Z}{I_{Z\min} + I_{L\max}}$$
