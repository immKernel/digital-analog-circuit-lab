# 模电实验二：单管低频电压放大电路 全景图解与实验指南

> **实验所属课程**：模拟电子技术基础实验（郑州大学 电工电子中心）  
> **对应指导书页码**：P3 ~ P6（PDF 第 4~7 页）  
> **核心研究目标**：静态工作点（Q点）对输出波形失真与放大倍数的影响，以及共射放大电路动态参数（$A_u, R_i, R_o$）的完整测量与计算方法。

---

## 一、实验目的
1. **掌握放大电路静态工作点的调试方法**：学习通过调节基极偏置电位器 $R_p$ 改变 $I_B, I_C, U_{CE}$，观察其对输出波形和放大倍数的影响。
2. **掌握放大电路动态参数的测量技能**：
   - 电压放大倍数 $A_u$（开路与带载）；
   - 输入电阻 $R_i$（串联已知电阻测量法）；
   - 输出电阻 $R_o$（接载前后电压变化法）；
   - 最大不失真输出电压 $U_{omax}$ 的测试。
3. **掌握放大电路常见失真波形的成因与消除方法**：深入理解饱和失真（削底）与截止失真（削顶）的物理机理及排除手段。
4. **熟练掌握示波器与交流毫伏表并联协同测量的规范**。

---

## 二、实验原理与电路图

### 2.1 实验电路图（图 2-1）
电路采用 NPN 型高频低噪声晶体三极管 **3DG6**（$\beta = 50\sim 80$），采用阻容耦合与固定+可调偏置结构：

![单管低频放大电路原理图](../images/exp2_circuit_schematic.svg)

- **供电电压**：$E_c = +12\text{V}$ 直流稳压电源
- **基极偏置支路**：固定限流电阻 $R_b' = 50\text{k}\sim 200\text{k}\Omega$ 串联电位器 $R_p = 1\text{M}\sim 2\text{M}\Omega$（总偏置电阻 $R_B = R_b' + R_p$）
- **集电极负载电阻**：$R_c = 3\text{k}\Omega$
- **负载电阻**：$R_L = 3\text{k}\Omega$
- **输入输出耦合电容**：$C_1 = C_2 = 10\mu\text{F}$（电解电容，注意正负极性！）
- **信号源内阻模拟电阻**：$R_s = 10\text{k}\Omega$

---

### 2.2 静态工作点（Q点）计算与调试原理
静态时（$u_i = 0$），电容 $C_1, C_2$ 起到隔直流作用，直流偏置通路如下：
$$I_B = \frac{E_c - U_{BE}}{R_B} = \frac{12\text{V} - 0.7\text{V}}{R_b' + R_p}$$
$$I_C = \beta I_B \approx I_E$$
$$U_{CE} = E_c - I_C R_c$$

#### 调 Q 点的物理链条：
$$\begin{aligned}
R_p \uparrow &\implies R_B \uparrow \implies I_B \downarrow \implies I_C \downarrow \implies U_{CE} \uparrow \; (\text{靠近 } E_c \text{，易截止失真}) \\
R_p \downarrow &\implies R_B \downarrow \implies I_B \uparrow \implies I_C \uparrow \implies U_{CE} \downarrow \; (\text{靠近 } 0\text{V} \text{，易饱和失真})
\end{aligned}$$

> **调试标准目标**：通过调节电位器 $R_p$，使集电极直流电位 $U_C = U_{CE} \approx 6.0\text{V} \sim 8.0\text{V}$（位于电源电压中点偏上，兼顾交流负载线动态对称）。

---

### 2.3 简化 h 微变等效电路与动态参数推导

在小信号交流通路中，直流电源 $E_c$ 对交流等效为接地，耦合电容 $C_1, C_2$ 容抗极小等效为短路：

![简化 h 微变等效电路与动态参数测量](../images/exp2_h_equivalent_circuit.svg)

#### 1. 晶体管输入电阻 $r_{be}$
$$r_{be} = 200\Omega + (1+\beta)\frac{26\text{mV}}{I_E \, (\text{mA})}$$
*若静态 $I_E \approx 1.5\text{mA}, \beta = 60$，则 $r_{be} \approx 200 + 61 \times \frac{26}{1.5} \approx 1257\Omega \approx 1.26\text{k}\Omega$。*

#### 2. 电压放大倍数 $A_u$
- **开路输出放大倍数（未接 $R_L$）**：
  $$A_{uo} = \frac{u_o'}{u_i} = -\beta \frac{R_c}{r_{be}}$$
- **带载输出放大倍数（接入 $R_L$）**：
  $$A_u = \frac{u_o}{u_i} = -\beta \frac{R_c // R_L}{r_{be}} = -\beta \frac{R_L'}{r_{be}}$$
  *其中 $R_L' = R_c // R_L = 3\text{k}\Omega // 3\text{k}\Omega = 1.5\text{k}\Omega$。*
  *负号表明：共射放大电路具有 **$180^\circ$ 的反相倒相特性**！*

#### 3. 输入电阻 $R_i$（串联电阻比较法，图 2-3）
放大电路本身的输入电阻定义为 $R_i = \frac{u_i}{I_i} = R_B // r_{be} \approx r_{be}$。  
实验中在信号源与电路输入端之间串接已知电阻 $R_s = 10\text{k}\Omega$：
$$R_i = \frac{u_i}{u_s - u_i} R_s$$

#### 4. 输出电阻 $R_o$（接载/开路法，图 2-4）
放大电路输出端等效为戴维南电压源 $u_o'$ 与内阻 $R_o$ 串联，理论值 $R_o \approx R_c$。  
实验测量公式：
$$R_o = \frac{u_o' - u_o}{u_o} R_L$$
*其中 $u_o'$ 为断开 $R_L$ 时的开路电压，$u_o$ 为接入负载 $R_L = 3\text{k}\Omega$ 后的端电压。*

## 三、波形失真特征与深度分析（思考题重点）

![静态工作点对输出波形失真的影响机理](../images/exp2_distortion_analysis.svg)

### 3.1 饱和失真（Q点过高，削底）
- **产生原因**：电位器 $R_p$ 调得过小，导致基极偏置电阻过小，静态电流 $I_B, I_C$ 过大，管压降 $U_{CE}$ 过低（接近 $0\text{V}$，低于饱和压降 $U_{CES}$）。
- **物理现象**：输入正半周时，三极管进入饱和区无法继续增大集电极电流，集电极电压无法继续下降；由于**共射放大反相**，输入正半周对应输出负半周，因此**输出波形下半周（底部）削平**！
- **消除方法**：顺时针调大 $R_p$ 阻值，减小基极电流 $I_B$，使 $U_C$ 升回 $6\sim 8\text{V}$。

### 3.2 截止失真（Q点过低，削顶）
- **产生原因**：电位器 $R_p$ 调得过大，基极偏置过小，$I_B, I_C$ 趋近于 0，管压降 $U_{CE}$ 异常偏高（接近电源电压 $E_c = +12\text{V}$）。
- **物理现象**：输入负半周时，发射结反偏进入截止区，$i_C = 0$，集电极电压被电阻 $R_c$ 钳位于 $E_c$ 电平；由于**共射反相**，输入负半周对应输出正半周，因此**输出波形上半周（顶部）削平**！
- **消除方法**：逆时针调小 $R_p$ 阻值，增大基极电流 $I_B$，使 $U_C$ 降回 $6\sim 8\text{V}$。

### 3.3 思考题 3 深度辨析：若采用 PNP 型三极管，失真情况如何？
- **NPN 管**：饱和失真削底（下部削平），截止失真削顶（上部削平）；
- **PNP 管**：由于电源极性为负电源（$-E_c$），其导通电流方向与电位极性完全相反，因此：
  - **饱和失真变为：上部削平（削顶）**；
  - **截止失真变为：下部削平（削底）**；
  - 两者现象正好完全倒置！

## 四、动态参数测试 SOP 流程与实操规范

![动态参数测试 SOP 流程全景图](../images/exp2_dynamic_measurement_flow.svg)

### 步骤 1：静态工作点设置与测量（记录表 2-1）
1. 断开交流信号输入（$u_i = 0$），将信号源拔出；
2. 接通 $+12\text{V}$ 直流稳压电源与系统地线；
3. 万用表直流电压档测量三极管集电极直流电位 $U_C$；
4. 慢慢调节电位器 $R_p$，使 $U_C = 6.0\text{V} \sim 8.0\text{V}$；
5. 分别用万用表测出晶体管三个电极对地电位：$U_B, U_C, U_E$；
6. 断开电源开关，拔开连线，用万用表电阻档测量此时的偏置电阻值 $R_B$。

### 步骤 2：动态信号注入与调试
1. 保持上述已调好的 $R_p$ 不动；
2. 信号发生器输出设为正弦波，频率 $f = 1\text{kHz}$，将输出幅度调节旋钮打至较小位置；
3. 示波器 CH1 探头接入电路输出端 $u_o$，监视波形；
4. 晶体管交流毫伏表接入输入端 $u_i$，微调信号源使输入交流信号为 $u_i = 5\sim 10\text{mV}$，确认输出波形完全光滑、对称且不失真。

### 步骤 3：放大倍数、输入电阻、输出电阻测定
1. **测 $A_u$（表 2-2）**：保持 $u_i$ 不变，毫伏表测带载输出电压 $u_o$（接入 $R_L=3\text{k}\Omega$），断开 $R_L$ 测开路输出电压 $u_o'$；
2. **测 $R_i$（表 2-3）**：毫伏表分别测量电阻 $R_s=10\text{k}\Omega$ 左侧电压 $u_s$ 与右侧输入端电压 $u_i$，代入公式计算；
3. **测 $R_o$（表 2-4）**：利用测得的开路 $u_o'$ 与带载 $u_o$，代入 $R_o = \frac{u_o' - u_o}{u_o} R_L$ 计算；
4. **测最大不失真输出幅度 $U_{omax}$**：缓慢增大信号源幅度，示波器观察波形在即将失真但仍未削顶/削底的临界瞬间，读取毫伏表输出有效值 $U_{omax}$。

## 五、实验故障排查与思考题解答

![故障树排查图](../images/exp2_troubleshooting_qpoint.svg)

### 思考题 1：$R_B$ 不拔下来，直接在电路中可以测量吗？
> **答：绝对不可以！**
> 1. **测量误差极大**：若在线测量，三极管发射结的正向等效内阻、电源内阻以及其他并联支路会并联在测试表笔之间，导致万用表测得的电阻值严重偏小于真实的 $R_B$；
> 2. **防烧表安全规范**：在电路未断电时，严禁使用万用表电阻档，否则外电路电压将直接损坏表头与内部电路。

### 思考题 2：在测静态时，发现 $U_C \approx E_c$（约 12V），应检查哪些元件？
> **答：** $U_C \approx E_c$ 意味着集电极电阻 $R_c$ 上没有电流流过（即集电极电流 $I_C = 0$），说明晶体管处于完全截止状态。应按以下顺序排查：
> 1. **基极回路断路**：检查固定偏置电阻 $R_b'$ 是否开路烧断、电位器 $R_p$ 触点是否磨损脱落或接触不良、电源到基极的连接线是否松脱；测 $U_B$，若 $U_B = 0\text{V}$ 即为基极无偏置；
> 2. **晶体三极管损坏**：检查三极管发射结是否内部烧断开路、或者管脚接错（b、c、e 插反）；
> 3. **发射极未接地**：检查三极管发射极 $e$ 与实验箱公共地（GND）之间连接线是否虚接断开；测 $U_E$，若 $U_E$ 浮空或异常即为地线不通。

### 思考题 3：若采用 PNP 型三极管，饱和失真和截止失真是上部失真还是下部失真？
> **答：**
> - **NPN 型管**：饱和失真为下部削平（削底），截止失真为上部削平（削顶）；
> - **PNP 型管**：由于供电为负电源且导电载流子相反，输出极性倒置，**饱和失真为上部削平（削顶），截止失真为下部削平（削底）**。
