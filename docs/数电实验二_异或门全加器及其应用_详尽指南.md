## 一、异或门 (74LS86) 基础与应用 (图 2-1)

![异或门与半加减器应用](../images/exp_dig2_xor_half_subtractor.svg)

### 1.1 异或门逻辑与受控传输
- 逻辑表达式：$Y = A \oplus B = \bar{A}B + A\bar{B}$。
- **作为受控反相器**：
  - 控制端 $M = 0 \implies Y = A \oplus 0 = A$（原码传输）
  - 控制端 $M = 1 \implies Y = A \oplus 1 = \bar{A}$（求反码传输）

### 1.2 半减器原理
- 差数：$D = A \oplus B$
- 借位数：$C_i = \bar{A} \cdot B$

### 1.3 奇偶校验器原理
- 多级级联异或：$Y = A \oplus B \oplus C \oplus D$
- 当输入代码中含有**奇数个 1** 时，输出为 1；含有偶数个 1 时，输出为 0。

## 二、四位二进制加法/减法器与代码转换 (图 2-2)

![全加器减法器与代码转换](../images/exp_dig2_adder_subtractor_8421.svg)

### 2.1 四位二进制加法/减法器（74LS83 + 74LS86）
- **核心计算模型**：
  $$F = A \pm B$$
- **加法模式（$M = 0$）**：
  加数 $B$ 经异或门原码输出，进位输入 $C_0 = M = 0$，执行 $F = A + B + 0 = A + B$。
- **减法模式（$M = 1$）**：
  加数 $B$ 经异或门求反码 $\bar{B}$，进位输入 $C_0 = M = 1$ 提供补码最低位所需的加 1，执行：
  $$F = A + \bar{B} + 1 = A + [-B]_补 = A - B$$
  *(重点解答思考题 1：做减法时 $C_0$ 必须接高电平 1 的本质原因！)*

### 2.2 8421 BCD 码向余 3 码转换电路
- 余 3 码定义：余 3 码 = 8421 码 + 3。
- 利用 74LS83，输入 $A$ 接 8421 码，输入 $B$ 接固定数值 $0011$（十进制 3），$C_0 = 0$，输出即为标准余 3 码。
